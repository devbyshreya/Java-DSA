
# Java & DSA Practice

Welcome to my Java & Data Structures and Algorithms (DSA) practice repository! This repository contains Java programs, coding exercises, and problem-solving practice as I continue improving my programming skills.

## About This Repository

This repository documents my learning journey in Java programming and DSA. It includes practice programs focused on strengthening programming fundamentals, understanding important data structures and algorithms, and improving logical thinking.

- **Core Java:** Variables, data types, loops, conditionals, and methods
- **Object-Oriented Programming:** Classes, objects, inheritance, polymorphism, abstraction, and encapsulation
- **Arrays and Strings:** Common operations and problem-solving
- **Searching and Sorting:** Basic searching and sorting algorithms
- **Data Structures:** Arrays, linked lists, stacks, and queues
- **Algorithms:** Recursion and basic algorithmic techniques
- **Problem Solving:** Coding exercises and practice challenges

*Topics will be added as I continue learning.*

## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- IntelliJ IDEA or another Java IDE

### Run the Programs

1. Clone this repository:

   ```bash
   git clone https://github.com/devbyshreya/Java-DSA-Practice.git
   ```

2. Open the project in IntelliJ IDEA.
3. Select the Java file you want to run.
4. Run the program using the IDE.
